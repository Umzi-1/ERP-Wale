# ERP Navigator

A lightweight web app concept to help businesses understand ERP, compare leading platforms, and shortlist the right ERP with a quick fit assessment.

## Features

- ERP education-focused landing page.
- Comparison snapshot of major OEM products (Odoo, Microsoft, SAP, Oracle).
- 4-question ERP fit assessment that generates a personalized shortlist.
- Lead capture form for matching users to implementation partners.

## Run locally

```bash
npm start
```

The server binds to `PORT` when provided (useful for cloud preview environments) and defaults to `3000`.

You can also run the static server directly:

```bash
python3 -m http.server 8000
```
